# Store listing

## English (default)
**App name:** Kirimly — Send to iPhone & Android

**Short description (≤80):** Send files between Android, iPhone and Mac. No app on iPhone, no internet.

**Full description:**
Kirimly moves photos, videos, documents and text between your devices, fast and private.

• iPhone, iPad and Mac need no app: scan a QR code and Safari opens Kirimly.
• No Wi-Fi? Kirimly creates a local hotspot, with a two-scan flow for iPhone.
• Android to Android works even without a shared network (Nearby Connections).
• Big files resume after a drop or a locked screen, and every file is checked with SHA-256.
• Android to Android is end-to-end encrypted, with a code to compare on both screens.
• You approve every incoming transfer; trusted devices can skip the PIN.
• Send whole folders, paste images on Mac, download everything as a ZIP.
• Clean black design, English and Indonesian.

No accounts, no ads, no tracking. Files never leave your devices.
